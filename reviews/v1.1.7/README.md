## 形式検証の範囲と残る制約

過去の署名済みレビュー判断は書き換えていない。現在も同じ文が存在する場合だけ参照を付け直した。消えた旧文への適用は記録付きで終了し、置換後の文に過去の承認を引き継いでいない。対応は `publication_retired_review_targets.json` に記録した。検査器の合格条件は緩めていない。

現在の抽出結果は5,188文。機械分類で外部根拠を要求する848文のうち、448文に直接の証拠対応を認識し、400文は未対応と判定している。これは引用抽出の結果であり、400文すべてが無根拠であることも、対応済みの文が科学的に証明されたことも意味しない。

制御された42件の形式化のうち40件で限定した含意が成立した。497件は仮定付き証明であり、本文全体の真実性を独立に証明したものではない。全文の自動証明・独立した真実性検証は0件。既存のレビュー完了フラグも `false` のまま維持した。リリースと検査の成功を、全記述の独立した査読完了として扱わない。
