# v1.1.8 追加図の image-gen 差し替え

確認日: 2026年9月5日

## 対象

v1.1.7 で追加した24点の SVG 図を、内蔵 `image_gen` で生成した PNG に差し替えた。
作業基点は main `3834f6ebc0e7b27192d71851af744ff9eb070c40`。
本文固定コミットは `fe2b276dbee9e80eceb22460de6337d92af0cd4d`。

本文の差分は画像パス24か所のみ。文章、図番号、参考文献、索引は維持した。
元から存在したほかの図と、利用者の未コミット資料は変更していない。
旧SVGは内容照合用に保持し、出版ビルドでの自動生成は終了した。

## 生成方法と記録

- 採用画像: `assets/images/v6/*.png`（24点、各1536×1024ピクセル）
- 使用方法: 内蔵 `image_gen`。CLI/API フォールバックは使用していない。
- モデル名はツール側で選択される。モデル指定の引数は公開されていないため、特定モデルを明示指定したとは記録しない。
- 初回生成・修正プロンプト: `print/imagegen-prompts.json`
- 画像のSHA-256、寸法、生成結果識別子、確認記録: `print/imagegen-manifest.json`

各画像の日本語、図の接続、数値例を目視確認した。修正も `image_gen` で行った。
SVGのラスタライズやプログラム描画を、生成画像の代わりに使っていない。
出版処理で作るグレースケールのコピーは、採用元のPNGを保持したまま生成する。

## 生成後に修正した点

- HyDE: 2番から3番へ進む矢印を補った。
- BM25: スコア0のD3をゼロ高で表した。
- SPLADE: 指定外の重み・スコアを除き、語の対応が見える図へ整理した。
- HNSW: 上層Fから下層Fへの接続を修正した。
- IVF/PQ: 同じ候補の部分距離を合計する図へ修正した。
- ColBERT: 文全体ではなく、各トークンにベクトルを描いた。
- MMR: 比較するAとCの関係線を修正した。
- MinHash: 指定外のハッシュ値を除き、最小値の列を比較する図にした。
- 評価指標: 取得のみX、共通A・B、必要な根拠のみCを明確に分けた。
- 二層: 生成指示から入り込んだ英語の補足文を除去した。
- READ: 掲載サイズで小さく見えた表を4セルへ整理し、本文ラベルを大きくした。

## 検証

- 出版処理の単体テスト11件に合格。画像24点の参照・PNGヘッダー・寸法・SHA-256も検査する。
- 本文差分が24の画像パスだけであることを確認した。
- 証拠台帳、意味の検査、文献との対応、レビュー適用、Lean の信頼性・追跡可能性の検査に合格した。
- Lean の24ジョブのビルドに成功した。
- Quint の型検査、14テスト、固定seed `0x726167`・5,000標本・最大12ステップの不変条件検査に合格した。

検証対象の本文コミットとファイルハッシュを更新した。過去のレビュー判断と検査の合格条件は変更していない。
証拠対応の集計は v1.1.7 と同じ（外部根拠要求848文、対応448文、未対応400文）。
レビュー完了フラグも `false` を維持した。形式検証の範囲に関する留保は、v1.1.7 の検証記録を引き継ぐ。

公開PDFのページ数・ハッシュと公開フローの結果は、作業PRの完了記録と GitHub Release を参照する。
