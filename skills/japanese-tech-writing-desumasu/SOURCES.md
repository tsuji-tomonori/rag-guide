# 調査資料と反映方針

調査日：2026-06-23

このファイルは、`SKILL.md` と `CHECKLIST.md` に追加した規則の根拠と、資料ごとの反映範囲を記録するものです。
各資料の文体や対象分野をそのまま移植するのではなく、日本語の技術文書を「です・ます調」で書く目的に合わせて統合しています。
投稿先、規格、法令、組織のスタイルガイドがある場合は、それらを優先します。

## 反映の要点

| 調査テーマ | 反映した内容 |
|---|---|
| 接続詞の表記 | 「さらに」「しかし」「したがって」「ただし」「また」などの仮名書き、一般向け文書での「および」「または」の使用 |
| 接続詞の機能 | 根拠と結論、因果、対応、対比、逆接、例外、補足、言換え、例示、列挙の使い分け |
| 並列・選択条件 | 「および」「ならびに」「または」「もしくは」の階層、網羅列挙と例示列挙、複雑な条件の構造化 |
| 接続詞の過剰使用 | すべての文・段落に接続詞を置かず、主語、トピックセンテンス、対象語の反復でも関係を示すこと |
| 文の構造 | 接続助詞「が」や連用形の中止法を連ねず、主語・述語・修飾語を近づけ、曖昧な読点を避けること |
| 科学的な論証 | 主張、根拠、論拠の対応、経験的事実と推論の区別、段落単位の論証 |
| 比較・統計・因果 | 対照と条件、独立した実験単位、反復、効果量と不確かさ、探索的解析、因果主張の根拠 |
| 実験・研究報告 | 目的、理論、方法、結果、考察、結論の役割、方法の再現・追跡可能性、結果と考察の分離 |
| 数値と単位 | SI単位、数値と単位記号の空白、量記号と単位記号の区別、有効数字、不確かさ、図表の単位 |
| 研究上の誠実さ | 正確さ、中立性、客観性、限界や不利な結果の明示、出典と追跡可能性 |
| 「から」の扱い | 学術文書で一律禁止せず、主観性・客観性、前後関係、分野の慣用、投稿規定を踏まえて「ので」「ため」「ことから」と使い分けること |

## 適用上の注意

- 参照資料には「だ・である調」で書かれたものがあります。本パッケージでは、内容上の原則を保持し、対象文書を「です・ます調」で書くための規則へ変換しています。
- 実験分野、計量学、統計学、医学、化学、情報工学などでは、同じ用語に専門的な定義があります。専門規格や投稿規定がある場合は、その定義を優先します。
- SI表記、図表、引用形式には媒体固有の規則があります。提出先が指定する形式を最終基準とします。
