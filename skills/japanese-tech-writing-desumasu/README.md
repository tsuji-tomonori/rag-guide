# 日本語技術文書「です・ます調」skills

バージョン：2.1.0

日本語の技術文書を、中立的で正確な「です・ます調」で作成・推敲するための規則をまとめたパッケージです。
今回の改訂では、日本語の接続詞の論理的な使い分けと、理科系文書として必要な科学的記述の要件を追加しました。

## ファイル

- `SKILL.md`：拡張済みのskills本体です。
- `CHECKLIST.md`：内容、科学的妥当性、接続詞、論理、文体、数値、図表、Markdownを確認するチェックリストです。
- `SOURCES.md`：調査した公的・学術的資料と、規則への反映箇所です。
- `CHANGELOG.md`：主な変更履歴です。
- `統合版.md`：skills本体、チェックリスト、調査資料、変更履歴を一つにまとめたファイルです。

## 主な内容

- 「だ・である調」との混在防止
- 能力、許可、必須、推奨、禁止、推定の書き分け
- 「したがって」「そのため」「そこで」「ただし」「なお」などの使い分け
- 「および」「ならびに」「または」「もしくは」と複雑な条件の構造化
- 接続詞の過剰使用、重複、論理の飛躍の検出
- 事実、観察、推論、考察、結論の分離
- 簡潔さや演出の規則と、再現・検証に必要な情報が競合する場合の優先順位
- 目的、方法、結果、考察、結論の役割
- 再現・追跡可能性に必要な条件とバージョンの記載
- SI単位、有効数字、不確かさ、数式、図表の扱い
- 比較条件、独立した実験単位、反復、統計、効果量、因果主張の確認
- 相関と因果、未検出と不存在、非有意と同等の区別
- 引用、出典、研究上の誠実さ
- 操作手順、仕様、APIリファレンス、実験報告、評価報告、障害対応ごとの運用
- 「〜となります」「〜させていただきます」などの過剰な敬語の抑制
- 機械検索と目視確認を組み合わせたチェックリスト

## 優先順位

投稿先、規格、法令、組織のテンプレート、用語集、スタイルガイドがある場合は、それらを優先してください。
特に研究論文や規格文書では、指定された文体、単位、引用形式、図表形式に従います。
