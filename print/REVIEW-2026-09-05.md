## 中心となるサーベイの扱い

対象はHuangとHuangの
[A Survey on Retrieval-Augmented Text Generation for Large Language Models](https://doi.org/10.1145/3805774)。
Crossrefの書誌情報では、ACM Computing Surveys 58巻12号、Article 300、1–38ページ、2026年。

ACM掲載版の本文はアクセス制限により取得できなかった。
内容の照合には、[公開著者版v2](https://arxiv.org/html/2404.10981v2)（2024年8月23日）を使った。
ACM最終掲載版との差分確認は残っている。

修正した主な点は次のとおり。

- 検索前処理には、資料側の処理と、質問の書き換えなど質問側の処理が含まれる。
  第2章で両方を定義し、第4章で質問側を詳しく説明する構成にした。
- 四工程は処理の目的による分類として扱う。
- Batch LayerとReal-time Layerという名称は維持した。
  質問への応答に依存するかを整理する本書の開発上の呼び名として説明した。
  増分取り込みもBatch Layerへ置けることを明示した。
- Naive・Advanced・Modularの分類は、Gaoらの別のサーベイへ帰属させた。
- サーベイによる分類、個別研究の実験結果、本書の設計上の提案を区別した。

## 技術的な修正

- 質問用と文書用の符号化器は、比較できるベクトル空間を共有する組み合わせを使う。
  DPRのように別々の重みを持つ方式があるため、「必ず同じモデル」という説明を修正した。
- DPRのtop-k retrieval accuracyを、複数の根拠に対するRecall@kと区別した。
  Hit@k、Recall@k、Precision@k、MRRの違いを数値例で示した。
- ALCEの引用再現率は、単なる引用の付与率ではなく、引用で文が支持される割合として説明した。
- BedrockのManaged／Customer-managed Knowledge Base、検索API、再順位付け、
  AgenticRetrieveStream、ACL対応検索などをAWS公式資料と照合した。
  Amazon Bedrockスキルの確認項目を使い、最終的には取得できた公式仕様を優先した。
- ACL対応検索と利用者の認証、API呼び出しの認可を分けた。
  利用者情報を渡す責任、ACL対象の情報源の扱い、権限変更の反映条件を明示した。

  画像情報の圧縮と選択的な展開を紹介した。選択器を含む学習が必要な方式として位置づけた。

## 再検査の方法

```sh
python3 -m unittest discover -s print -p 'test_*.py' -v
make -C print
python3 print/audit_pdf.py dist/rag-engineering-guide.pdf
git diff --check
```

自動検査では、文献メタデータ、太字用語の収録、技術名、図番号、画像ファイル、
表の列数と組版方式、コードブロックの保持、図中の計算例を確かめる。
PDFの位置検査では本文の左右へのはみ出しを調べる。
図・表・参考文献・索引は、PDFを画像に描画して目視も行う。

最終結果：341ページ。自動テスト7項目はすべて通過した。
本文の左右へのはみ出し、LaTeXのOverfull、欠落文字、未解決参照は検出されなかった。
makeindexは1,001件の参照位置を受理し、拒否・警告は0件だった。
参考文献・索引・奥付の目次項目は、それぞれ1件であることを確認した。
細かな数式用フォントにはサイズ代替の警告がある。表全体の縮小には使っていない。
詳細な集計は`print/build/publication-audit.json`と`print/build/pdf-audit.json`へ出力した。
