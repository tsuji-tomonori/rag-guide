# 10.5. 根拠整形と生成を接続する

## 10.5.1. 一体型と分離型を使い分ける

ここでいう一体型の`RetrieveAndGenerate`は、カスタマーマネージド型のKnowledge Baseでだけ使用します。AWSの[RetrieveAndGenerate API Reference](https://docs.aws.amazon.com/bedrock/latest/APIReference/API_agent-runtime_RetrieveAndGenerate.html)に示されるとおり、Managed Knowledge Baseでは使用できません。Managed Knowledge Baseでは`Retrieve`または`AgenticRetrieveStream`で根拠を取得し、生成が必要な場合は結果を`Converse`へ渡します。

カスタマーマネージド型でKnowledge Basesの標準引用と生成が要件を満たす場合は`RetrieveAndGenerate`を使います。検索結果の重複、版、矛盾、根拠不足を独自に検査する場合は、`Retrieve → LambdaでEvidence Set作成 → Converse`へ分けます。

| 管理方式 | 標準経路 | 独自の根拠整形を入れる経路 |
|---|---|---|
| カスタマーマネージド型 | `RetrieveAndGenerate` | `Retrieve → 検索後処理 → Converse` |
| Managed Knowledge Base | `Retrieve`または`AgenticRetrieveStream` → `Converse` | `Retrieve`または`AgenticRetrieveStream` → 検索後処理 → `Converse` |

分離型では、Retrieveの結果から`text`、`location`、`metadata`、`score`を受け取り、`citation_id`、`chunk_id`、`document_id`、`version`、`source_uri`、`retrieval_rank`、`text`へ正規化します。scoreだけで採否を決めず、重複、最新版、出典、質問の論点を検査します。

## 10.5.2. Evidence Setとpromptを固定する

生成modelには、命令とEvidence Setを別のblockで渡します。各根拠を`<evidence id="E01">...</evidence>`のように識別し、回答の各主張へ`E01`形式のcitation IDを付けるようにします。根拠外の推測を禁止するだけでなく、根拠不足、矛盾、対象外質問の出力形式を明示します。

Evidence Setの件数とtoken数には上限を置きます。初期値はrerank後5件とし、質問の論点を満たさない場合は件数を増やすのではなく、[Evidence validationとfallback](../5.根拠を選別・整形する/5.8.Evidence validationとfallback.md)へ戻して再検索または回答保留を選びます。

## 10.5.3. 生成後にcitationを検査する

Converseのstructured outputまたはアプリケーションschemaで、`answer`、`claims[]`、`citation_ids[]`、`answerable`、`reason`を返します。JSON Schemaで出力を制約できるmodelとregionは利用時点の[対応状況](https://docs.aws.amazon.com/bedrock/latest/userguide/structured-output.html)を確認し、非対応の場合もアプリケーション側で同じschemaを検証します。schema違反は検証errorだけを添えて1回まで再生成し、なお失敗する場合は`answerable=false`として回答保留へfallbackします。

生成後は、未知のcitation ID、citationのない検証可能な主張、取得本文に支持されない主張を検出します。JSONとして読めることだけを成功条件にせず、すべての`citation_ids`がEvidence Set内に存在し、各claimが参照本文に支持されることを確認します。

Amazon Bedrock Guardrailsは有害内容や機密情報の検査へ使えますが、根拠の正しさや文書アクセス条件を検証する機能ではありません。RAG固有のcitation検査、claim support、answerabilityは[根拠に基づく回答](../6.根拠に基づいて回答する/序文.md)の基準で別に実装します。
