# 3. 回答に使う資料を準備する

良い回答は、質問が来てから急に作られるわけではありません。どの資料を正しい情報源とするか、古い版や重複をどう扱うか、表やPDFをどう解析するかという事前準備が、検索品質の上限を決めます。

本章では、データソースの棚卸しからindexの構築までを扱います。最後のPublish前ゲートは壊れた成果物を公開しないための最小確認に限定し、品質指標、golden dataset、回帰評価、release判定は第7章へ委ねます。

本章の節を、次のラベル付きトピック群に分けます。

| トピック群 | 対象節 | 設計上の問い |
|---|---|---|
| G3-A 情報源統制 | 3.1、3.2 | 何を、いつ、どの版として取り込むか |
| G3-B 検索単位形成 | 3.3、3.4 | 文書構造と出典位置を保って分割できるか |
| G3-C 索引表現 | 3.5、3.6、3.7 | 属性、権限、ベクトル、索引を再現できるか |
| G3-D 公開判定 | 3.8 | 欠損や失敗を検出して公開を止められるか |

各トピック群では、設計対象、実行制御、評価・停止条件の順に確認します。
