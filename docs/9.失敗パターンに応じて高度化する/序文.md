# 9. 失敗パターンに応じて高度化する

基本的なRAGで評価した後にも、会話文脈、複数source、構造化データ、長文、関係探索、図表、業務操作などに固有の失敗が残る場合があります。

本章では、技術名から導入を決めず、観測した失敗パターンから必要な高度化を選びます。各方式について、効く問題、前提、評価指標、安全性、cost、導入判断を同じ順序で確認します。

本章では、代表研究が一定数引用され、複数の査読付き研究で効果が確認できる方式だけを扱います。
引用件数は時点、索引、著者統合、版の扱いによって変わるため、本文には固定値として掲載しません。件数を再調査するときは、取得元、検索式、論文のcanonical ID、取得時刻、保存した生応答への相対パスとSHA-256を `evidence/chapter-9-citation-counts/` に残します。掲載判断では、引用件数だけでなく、独立研究、対象タスク、比較条件、査読状況を確認します。

各方式の根拠と掲載範囲を次に示します。

- **Conversational RAG**は、[ConvGQR](https://aclanthology.org/2023.acl-long.274/)と[IterCQR](https://aclanthology.org/2024.naacl-long.449/)を根拠に、会話中の省略を解決する検索書き換えを扱います。
- **Federated・Routed RAG**は、[Adaptive-RAG](https://aclanthology.org/2024.naacl-long.389/)と[When and How to Augment Your Input](https://aclanthology.org/2025.findings-naacl.200/)を根拠に、情報源別のRecallと費用を測るルーティングを扱います。
- **Structured Data RAG**は、[Spider](https://aclanthology.org/D18-1425/)と[RAT-SQL](https://aclanthology.org/2020.acl-main.677/)を根拠に、読み取り専用、許可スキーマ、実行検証を備えた構成を扱います。
- **Long-context RAG**は、[Retrieval Meets Long Context](https://openreview.net/forum?id=xw5nxFWMlo)と[Lost in the Middle](https://aclanthology.org/2024.tacl-1.9/)を根拠に、長文直接入力、検索、併用を比較します。
- **Hierarchical RAG**は、[RAPTOR](https://proceedings.iclr.cc/paper_files/paper/2024/hash/8a2acd174940dbca361a6398a4f9df91-Abstract-Conference.html)と[Dynamic Tree Memory](https://proceedings.iclr.cc/paper_files/paper/2025/file/0382cb76309820f71c6eacd47b36ce71-Paper-Conference.pdf)を根拠に、概要質問と要約誤りの評価を扱います。
- **GraphRAG**は、[G-Retriever](https://proceedings.neurips.cc/paper_files/paper/2024/file/efaf1c9726648c8ba363a5c927440529-Paper-Conference.pdf)、[HippoRAG](https://proceedings.neurips.cc/paper_files/paper/2024/hash/6ddc001d07ca4f319af96a3024f6dbd1-Abstract-Conference.html)、[KnowGPT](https://proceedings.neurips.cc/paper_files/paper/2024/hash/0b8705a611ed1ce19cdb759031078705-Abstract-Conference.html)を根拠に、関係検索として扱います。各研究のグラフ構築法と評価条件を区別して比較します。
- **Multimodal RAG**は、[ColPali](https://proceedings.iclr.cc/paper_files/paper/2025/file/99e9e141aafc314f76b0ca3dd66898b3-Paper-Conference.pdf)と[Document Screenshot Embedding](https://aclanthology.org/2024.emnlp-main.373/)を根拠に、文書画像、レイアウト、表の検索を扱います。
- **Agentic RAG**は、[ReAct](https://openreview.net/forum?id=WE_vluYUL-X)と[IRCoT](https://aclanthology.org/2023.acl-long.557/)を根拠に、一つのエージェントによる検索反復を扱います。
- **Retrieval-aware training**は、[REALM](https://proceedings.mlr.press/v119/guu20a.html)と[RETRO](https://proceedings.mlr.press/v162/borgeaud22a.html)を根拠に、検索を結合する位置と費用を比較します。RAFTとRA-DITは、それぞれの評価条件に限定して扱います。

製品固有のルーターや生成SQLを無条件に有効とみなさず、情報源別の検索Recall、実行制約、認可を評価します。

各方式は、対象となる失敗、仕組み、研究上の根拠、評価方法、停止条件の順に確認します。単一の指標や一つのデータセットだけで一般化せず、基本構成との差を同じ評価データで測ります。
