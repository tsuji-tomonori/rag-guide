# 1. RAGとは何か

**RAG（Retrieval-Augmented Generation、検索拡張生成）**とは、**AI（Artificial Intelligence、人工知能）**が答える前に必要な資料を探し、その資料を根拠にして回答する考え方です。AIの内部知識に加えて、社内規程、製品資料、手順書など、更新と確認が可能な情報を回答に利用します。

情報源、検索、回答、引用を一つのシステムとして管理すると、根拠を確認し、答えられる範囲を示し、誤りの発生箇所を調べられます。回答の正しさは、情報源の管理、工程別の評価、回答後の検証を通じて確かめます。

本章では、**LLM（Large Language Model、大規模言語モデル）**単体や検索システムとの違い、RAGが解決する問題、適用しやすいケース、別の方式を選ぶケースを整理します。後続章の技術を理解するために、検索、根拠の選別、回答生成、評価がつながる全体像も示します。具体的な構成は[全体アーキテクチャ](../2.アーキテクチャ/序文.md)で確認できます。
