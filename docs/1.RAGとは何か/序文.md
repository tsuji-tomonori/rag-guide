# 1. RAGとは何か

RAGとは、AIが答える前に必要な資料を探し、その資料を根拠にして回答する考え方です。AIの内部知識だけに頼らず、社内規程、製品資料、手順書など、更新と確認が可能な情報を回答に利用します。

RAGは、回答の正しさを保証する仕組みではありません。情報源、検索、回答、引用を一つのシステムとして管理することで、根拠を確認し、分からないときには無理に答えず、誤りの発生箇所を調べやすくします。

本章では、LLM単体や検索システムとの違い、RAGが解決する問題、向くケースと向かないケースを整理します。後続章の技術を理解するために、検索、根拠の選別、回答生成、評価がつながる全体像も示します。具体的な構成は[全体アーキテクチャ](../2.アーキテクチャ/序文.md)で確認できます。
