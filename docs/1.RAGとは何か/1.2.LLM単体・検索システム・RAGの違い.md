# 1.2. LLM単体・検索システム・RAGの違い

## 1.2.1. 三つの方式の比較

同じ質問へ答える場合でも、方式ごとに情報源、出力、適する用途が異なります。

- **LLM単体**は、モデルの学習結果と入力文から回答を生成します。文章作成や一般知識の説明に向き、学習後に変わる情報は入力文で与えます。
- **検索システム**は、検索対象の文書から該当する文書または箇所を返します。原文の確認に向き、複数資料の統合と結論は利用者が行います。
- **RAG**は、検索対象の文書とLLMを組み合わせ、根拠に基づく回答と引用を返します。文書の探索、要約、統合に向き、検索品質、回答品質、引用による支持を一体で評価します。

[Dense Passage Retrieval](https://aclanthology.org/2020.emnlp-main.550/)は、質問に関係する文章を密なベクトル表現で検索できることを示しました。
RAGは、このような検索器の結果を言語モデルへ渡します。

## 1.2.2. 近隣技術との使い分け

**ファインチューニング**は、モデルの振る舞いや出力形式を調整する用途に向きます。
頻繁に変わる事実を更新する目的では、情報源を差し替えられるRAGの方が管理しやすい場合があります。

**長いコンテキスト**は、少数の文書をそのまま入力できる場合に有効です。
文書数が多い場合、権限や鮮度で選別する場合、または検索結果を監査する場合は、RAGと組み合わせます。

**ツール利用**は、データベース照会、計算、状態変更など、文書検索だけでは完結しない処理に使います。
RAGと競合する方式ではなく、処理の種類に応じて併用する方式です。
