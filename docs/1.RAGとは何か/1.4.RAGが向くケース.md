# 1.4. RAGが向くケース

次の条件を満たす業務は、RAGの候補になります。

- 回答の根拠となる文書が存在します。
- 文書の所有者、版、利用権限を管理できます。
- 質問に関係する箇所を検索で絞る必要があります。
- 回答と引用を人または評価処理で確認できます。

| 用途 | 利用する情報 | RAGで行う処理 |
|---|---|---|
| 社内規程の照会 | 規程、手順書、通達 | 該当条件を検索し、版を示して回答します |
| 製品サポート | 仕様書、FAQ、障害情報 | 製品と版を絞り、手順と根拠を提示します |
| 技術調査 | 論文、設計資料、コード文書 | 複数資料を検索し、出典付きで整理します |
| 障害対応支援 | Runbook、過去事例、構成情報 | 症状に関係する手順を検索し、確認順を提示します |

この表は導入効果を保証するものではありません。
実際の質問と正解根拠を使って、検索品質、回答品質、応答時間、費用、安全性を評価します。
