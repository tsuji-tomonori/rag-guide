# 1.7. RAGを支える研究

## 1.7.1. 基礎となる研究

RAGは、情報検索と自然言語生成の研究を組み合わせた方式です。
本書の第1章から第8章では、査読付き研究で繰り返し評価され、一般的なRAGにも適用できる次の知識を基礎にします。

- [BM25の確率的検索モデル](https://doi.org/10.1561/1500000019)
- [Dense Passage Retrieval](https://aclanthology.org/2020.emnlp-main.550/)
- [Retrieval-Augmented Generation](https://proceedings.neurips.cc/paper/2020/hash/6b493230205f780e1bc26945df7481e5-Abstract.html)
- [BEIRによる検索方式の横断評価](https://datasets-benchmarks-proceedings.neurips.cc/paper/2021/hash/65b9eea6e1cc6bb9f0cd2a47751a186f-Abstract-round2.html)
- [FEVERによる根拠支持・反証・情報不足の評価](https://aclanthology.org/N18-1074/)
- [ALCEによる引用評価](https://aclanthology.org/2023.emnlp-main.398/)

本ガイドでは、本節で取り上げた研究結果を、すべてのデータや業務で同じ効果を保証する根拠として扱いません。
例えば、BEIRは検索方式の優劣がデータセットによって変わることを示しています。
本書では、基礎技術であっても固定値や効果を一般化せず、対象データによる評価を求めます。

## 1.7.2. 先進技術の扱い

第9章では、会話検索、長文検索、グラフ検索、マルチモーダル検索、反復検索などを扱います。
掲載対象は、代表研究に一定の引用実績があり、複数の独立した査読付き研究で効果または課題が報告されている技術に限定します。

先進技術は、標準構成より優れているとは限りません。
再現できる失敗に対して比較実験を行い、品質、応答時間、費用、安全性の総合結果で採否を決めます。
