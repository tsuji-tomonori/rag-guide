# 8. 安全に運用する

業務でRAGを使うには、正しい回答だけでなく、権限外資料を見せないこと、機密情報を守ること、遅延と費用を管理すること、問題の原因を追えることが必要です。

本章では、セキュリティ、privacy、攻撃対策、監査、性能、cost、知識更新、governanceを横断的に扱います。これらは後付けの機能ではなく、第3章から第7章の全工程へ適用する制約です。

本章の節を、次のラベル付きトピック群に分けます。

| トピック群 | 対象節 | 運用上の問い |
|---|---|---|
| G8-A 情報保護 | 8.1から8.3 | 権限外利用、機密漏えい、入力攻撃を抑制できるか |
| G8-B 証跡 | 8.4 | 誰が何を参照し、何を返したかを追跡できるか |
| G8-C サービス維持 | 8.5、8.6 | 性能、可用性、費用を継続して管理できるか |
| G8-D 変更統制 | 8.7、8.8 | 知識と構成の更新を承認し、切り戻せるか |

各トピック群では、保護対象、実行制御、監視・停止条件の順に確認します。
