# 8. 安全に運用する

業務でRAGを使うには、正しい回答だけでなく、権限外資料を見せないこと、機密情報を守ること、遅延と費用を管理すること、問題の原因を追えることが必要です。

本章では、セキュリティ、privacy、攻撃対策、監査、性能、cost、知識更新、governanceを横断的に扱います。
これらは後付けの機能ではなく、第3章から第7章の全工程へ適用する制約です。

認可は回答生成後に隠すのではなく、取り込み、検索、取得後確認の各段階へ適用します。
外部資料や取得文は命令ではなくdataとして扱い、prompt injectionやpoisoningが後段の操作へ伝播しない境界を設けます。

運用では、回答品質だけでなく、文書更新と削除の反映、構成version、処理trace、遅延、失敗率、単価を観測します。
異常時に新規処理を止め、旧版へ戻し、影響した回答を追跡できる状態を維持します。
