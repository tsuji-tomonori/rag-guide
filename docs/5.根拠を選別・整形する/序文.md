# 5. 根拠候補をEvidence Setに整える

資料を見つけても、そのままLLMへ渡せば良い回答になるとは限りません。重複、古い版、低信頼source、矛盾、token超過を整理し、回答に必要な根拠だけを追跡可能な形でまとめます。

本章では、候補の正規化、重複排除、reranking、compressionを経てEvidence Setを作り、contextへ配置するまでを扱います。回答文の生成、引用表示、回答保留は第6章で扱います。
