# 5. 根拠候補をEvidence Setに整える

資料を見つけても、そのままLLMへ渡せば良い回答になるとは限りません。重複、古い版、低信頼source、矛盾、token超過を整理し、回答に必要な根拠だけを追跡可能な形でまとめます。

本章では、候補の正規化、重複排除、reranking、compressionを経てEvidence Setを作り、contextへ配置するまでを扱います。回答文の生成、引用表示、回答保留は第6章で扱います。

本章の節を、次のラベル付きトピック群に分けます。

| トピック群 | 対象節 | 設計上の問い |
|---|---|---|
| G5-A 候補整流 | 5.1、5.2 | 比較可能な候補へそろえ、重複を抑えられるか |
| G5-B 関連度最適化 | 5.3、5.4 | 必要な根拠を残して長さを抑えられるか |
| G5-C 根拠集合化 | 5.5、5.6 | 出典を保って回答用の順序へ配置できるか |
| G5-D 不確実性処理 | 5.7、5.8 | 矛盾、古い根拠、根拠不足を検出できるか |

各トピック群では、設計対象、実行制御、評価・停止条件の順に確認します。
