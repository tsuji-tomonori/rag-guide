# 2.2 第3章から第9章の全体地図

第3章から第8章は、多くのRAGシステムで必要になる基礎を扱います。
第9章は、基礎構成を評価した後に、再現した失敗へ対応する高度化を扱います。

| 章 | ラベル | 判断すること | 主な成果 |
|---|---|---|---|
| 第3章 | 資料準備 | 何を、どの単位で、どの版として検索させるか | 検索可能な索引 |
| 第4章 | 候補検索 | 必要な根拠を候補へ残せるか | 根拠候補 |
| 第5章 | 根拠確定 | 候補から回答に使う根拠を選べるか | 根拠集合 |
| 第6章 | 回答生成 | 根拠の範囲で回答し、引用または保留を返せるか | 検査可能な回答 |
| 第7章 | 品質評価 | どの工程が品質を制約したか | 評価結果と改善判断 |
| 第8章 | 安全運用 | 権限、更新、監査、性能を維持できるか | 運用統制 |
| 第9章 | 条件付き高度化 | 基礎構成で残る失敗に、追加方式が有効か | 採否と停止条件 |

各章は、「設計対象」「実行制御」「評価・停止条件」という共通の観点で整理します。
節ごとのトピック群は、各章の冒頭に示します。
