# 2.2 資料準備側の処理

資料準備側は、質問が来る前に知識源を検索可能な状態へ変える処理です。ここでは処理順と責務を確認し、parser、chunk、embedding、indexの選択は[回答に使う資料を準備する](../3.回答に使う資料を準備する/序文.md)で扱います。

最初に、RAGが参照してよいdata sourceを定めます。正本、所有者、更新頻度、版、有効期間、機密区分を記録し、検索対象外にするsourceも明示します。接続できる資料を無条件に取り込むと、古い版や権限外の資料が回答へ混入します。

PDF、Office文書、HTML、表、画像などを、読み順と出典位置を保ったcanonical documentへ変換します。解析に失敗した文書を黙って登録せず、失敗理由と再処理可否を記録します。文書は検索と引用に適したchunkへ分けますが、小さすぎれば文脈を失い、大きすぎれば検索精度とtoken効率を下げるため、文書構造と質問の粒度に合わせます。

各documentとchunkへ、source、版、時点、分類、provenance、ACLを付与します。chunkをembedding化してsparseまたはvector indexへ登録するときは、model、dimension、distance、index schemaをversion付きで固定します。回答側が参照するのは公開済みversionのindexであり、作成途中の成果物ではありません。
