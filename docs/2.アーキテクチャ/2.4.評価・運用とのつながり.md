# 2.4 役割別の読み方

| 役割 | 先に読む章・節 | 次に確認する章 |
|---|---|---|
| 決裁者、部長、営業 | 第1章、2.1、2.3 | 第7章、第8章 |
| アプリケーションエンジニア | 2.1、2.2 | 第4章から第7章、第9章、AWS実装時は第10章 |
| インフラエンジニア | 2.1、2.3 | 第3章、第8章、第10章 |
| DB・検索エンジニア | 2.1、2.2 | 第3章から第5章、第7章、ACLとキャッシュは第8章 |
| QAエンジニア | 2.3 | 第6章から第8章 |

第10章は、第3章から第9章の設計をAWSサービスへ対応付ける実装ガイドです。
製品名から読み始めるのではなく、第2章で対象工程を確認してから参照します。
