# 2.7 非機能と運用の概要

非機能は、RAGが品質を保って利用され続けるための条件です。
アクセス制御、プライバシー、監査、性能、可用性、費用、知識更新、ガバナンスを四工程へ適用します。

## 2.7.1 情報と処理の境界を守る

アクセス制御は、取り込み時の属性、検索時の候補制約、生成前の最終確認へ一貫して適用します。
機密情報は、本文だけでなく、埋め込み、検索候補、引用、実行記録、評価データでも同じ保護区分を維持します。

検索対象の文書は参照データとして扱い、文書内の命令とシステムの命令を分離します。
監査では、利用者、質問、適用した権限、取得候補、採用根拠、回答、構成版を追跡できる状態にします。

## 2.7.2 継続運用の条件を測る

性能と可用性は工程ごとの応答時間、タイムアウト、代替経路、処理量で測ります。
費用は、取り込み、埋め込み、検索、再順位付け、生成、評価の単位に分け、質問種類と構成版へ結び付けます。

文書の追加、変更、削除、権限変更を索引とキャッシュへ反映し、公開済み版と切り戻し先を管理します。
具体的な統制と評価方法は[安全に運用する](../8.安全に運用する/序文.md)で扱います。
