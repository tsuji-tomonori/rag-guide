# 2. 全体アーキテクチャ

RAGを業務で使うには、質問に答える画面だけでなく、資料を準備する処理、質問ごとに根拠を探して回答する処理、品質を評価して安全に運用する仕組みが必要です。

本章は後続章を読むための地図です。管理項目やschemaを列挙するのではなく、処理の流れと責務の境界を簡潔に示します。詳細な資料準備は第3章、検索から回答までは第4章から第6章、評価は第7章、運用は第8章、高度化は第9章で扱います。
