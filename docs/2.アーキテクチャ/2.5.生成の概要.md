# 2.5 生成の概要

生成は、質問とEvidence Setから、根拠が支える回答、引用、または回答保留を作る工程です。
入力では命令と根拠を構造的に分け、出力では回答本文、引用、回答状態を分けて扱います。

## 2.5.1 根拠が支える範囲で回答する

プロンプトには、Evidence Setに含まれる情報を根拠として使うこと、主張へ引用を対応付けること、根拠の適用範囲を保つことを指定します。
回答形式は、本文だけでなく、引用先、参照した版、回答可能性をアプリケーションが検査できる構造にします。

複数の根拠を統合する場合は、各主張をどの根拠が支えるか確認します。
矛盾が残る場合は相違点と確認できた範囲を示し、十分な根拠が揃う範囲へ回答を限定します。

## 2.5.2 回答保留を正常な出力として扱う

回答保留は、必要な根拠、権限、対象条件のいずれかが不足した状態を利用者へ伝える出力です。
不足している条件が特定できる場合は確認質問へ進み、情報源に答えが存在する可能性がある場合は追加検索へ戻します。

回答生成、引用、主張検証、会話履歴、業務実行との境界は[根拠に基づいて回答する](../6.根拠に基づいて回答する/序文.md)で扱います。
