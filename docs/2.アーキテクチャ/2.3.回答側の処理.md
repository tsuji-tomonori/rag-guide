# 2.3 回答側の処理

回答側は、質問ごとに根拠候補を取得し、回答に使える形へ整え、引用可能な回答を生成する処理です。検索、根拠整形、生成の詳細は[質問に合う根拠候補を探す](../4.質問に合う根拠を探す/序文.md)、[根拠候補をEvidence Setに整える](../5.根拠を選別・整形する/序文.md)、[根拠に基づいて回答する](../6.根拠に基づいて回答する/序文.md)で扱います。

質問から対象、意図、版、期間、否定条件、会話中の省略を読み取り、検索計画へ変換します。keyword、semantic、metadata filterを組み合わせ、正解根拠を含み得るcandidate集合を作ります。この段階の役割は最終回答を決めることではなく、必要な根拠を後段へ残すことです。

candidateを権限、鮮度、版、信頼度で絞り、重複を除き、質問への適合度でrerankします。選択した根拠はEvidence Setとして整理し、supporting、conflicting、backgroundなどの役割とprovenanceを持たせます。token budgetへ収めるときも引用位置を失わないようにします。

LLMには命令とEvidence Setを区別して渡し、根拠が支える範囲で回答させます。根拠不足、権限不足、矛盾が解消できない場合は、回答保留を正常な出力として返します。検索候補、採用根拠、引用、modelとpromptの版をtraceへ残すと、最終回答の誤りを発生工程へ戻せます。
