# 2.3 失敗の見取り図

最終回答だけを見ても、原因は特定できません。
次の順で工程を確認します。

| 症状 | 最初に確認する章 | 代表的な確認対象 |
|---|---|---|
| 資料が検索対象にない | 第3章 | 解析、分割、索引、版、権限 |
| 正しい根拠が候補にない | 第4章 | 質問表現、語彙、ベクトル、フィルター |
| 候補はあるが採用されない | 第5章 | 並べ替え、重複、長さ、矛盾 |
| 根拠はあるが回答が誤る | 第6章 | 指示、引用、保留条件、出力検査 |
| 改善効果を判断できない | 第7章 | データセット、指標、回帰試験 |
| 情報漏えいや更新遅延がある | 第8章 | 認可、監査、削除、監視 |
| 基礎方式の限界が残る | 第9章 | 高度化の適用条件と追加コスト |

高度化は、失敗箇所を特定してから選びます。
技術名を先に選ぶと、効果の原因と追加コストを判断しにくくなります。
