# 2.2. 検索前処理の概要

検索前処理は、文書と質問を検索へ渡せる状態に整える工程です。
Batch Layerでは文書から索引を作り、Real-time Layerでは質問から検索条件と検索クエリを作ります。
二つの経路が同じメタデータ定義、版、検索方式を共有すると、質問の条件を索引へ正しく適用できます。

## 2.2.1. Batch Layerで文書を準備する

最初に、参照する情報源の正本、所有者、更新頻度、版、有効期間、機密区分を定めます。
続いて、文書の読み順と出典位置を保って解析し、検索と引用に適した単位へ分けます。
各文書とチャンクには、出典、版、時点、分類、来歴、アクセス制御属性を付けます。

本ガイドの取り込みでは、同じdocument versionから、語彙一致用のsparse indexと意味類似用のembedding・vector indexを作成します。
公開前ゲートで件数、欠損、権限、削除反映、検索品質を確認し、合格した索引版をReal-time Layerへ公開します。
具体的な設計は[回答に使う資料を準備する](../3.回答に使う資料を準備する/序文.md)で扱います。

## 2.2.2. Real-time Layerで質問を準備する

質問から対象、意図、版、期間、否定条件、会話中の省略を読み取り、検索計画へ変換します。
語彙一致が必要な識別子、意味検索が適する言い換え、メタデータへ適用する条件を分けることで、後続の検索方式を選べます。

質問変換を行う場合は、元の意味、制約、固有名詞を保持し、元質問と変換後の質問を同じ実行記録へ残します。
具体的な処理は[Query理解と検索計画](../4.質問に合う根拠を探す/4.1.Query理解と検索計画.md)と[Query変換](../4.質問に合う根拠を探す/4.2.Query変換.md)で扱います。
