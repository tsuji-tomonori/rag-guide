# 6. 根拠に基づいて回答する

本章では、Evidence Setから根拠に基づく回答を作ります。資料に書かれていることとモデルの推測を混ぜず、根拠が足りない場合は回答範囲を狭めるか、回答を保留します。

回答形式、answerability、citation、複数根拠の統合、claim単位の検証、会話履歴を扱います。業務システムへのaction実行は本章の中心に置かず、境界だけを示して、詳細を第9章のAgentic RAGと第8章の認可・監査へ委ねます。

本章の節を、次のラベル付きトピック群に分けます。

| トピック群 | 対象節 | 設計上の問い |
|---|---|---|
| G6-A 生成契約 | 6.1、6.2 | 根拠と命令を分け、検査可能な形式で返せるか |
| G6-B 回答可能性 | 6.3、6.4 | 根拠不足を保留し、引用位置を示せるか |
| G6-C 主張検証 | 6.5、6.6 | 複数根拠と各主張の支持関係を確認できるか |
| G6-D 状態と境界 | 6.7、6.8 | 会話状態と業務操作を回答生成から分離できるか |

各トピック群では、設計対象、実行制御、評価・停止条件の順に確認します。
