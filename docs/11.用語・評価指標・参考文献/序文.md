# 11. 用語・評価指標・参考文献

本章は、本文を章をまたいで参照するための巻末資料です。用語の別称、評価指標の分母と測定位置、本文で中核的に扱った学術文献をまとめます。製品のAPI、上限、対応リージョンなど変わりやすい情報は、本文中の公式ドキュメントへのリンクを利用時点で確認します。

**この章を読むと決められること**：同じ語を同じ意味で使えているか、どの工程でどの指標を測るか、設計判断の原典をどこまで遡るかを確認できます。

節へのリンクは、Markdownでは正本ファイルへ、PDFでは節番号とページ番号へ移動します。固定ページ番号を本文へ埋め込まないため、改版後も初出箇所を追跡できます。
