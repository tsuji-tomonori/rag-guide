# 11.1. 用語集

用語集は、本書で近い意味に見えやすい語の境界を示します。「別称」は本文中で同じ概念を指す表記です。似ていても評価単位や工程が異なる語は、同義語としてまとめません。

**表11-1　本書の主要用語と初出**

| 情報源 | Source | source | 回答の正本または根拠候補として管理する文書・データです | [1.1.](../1.RAGとは何か/1.1.RAGとは.md) |
| 検索前処理 | Pre-retrieval | - | 文書と質問を検索可能な表現へ変える工程です | [2.1.](../2.アーキテクチャ/2.1.RAGパイプライン全体像.md) |
