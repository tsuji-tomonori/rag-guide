# RAG勉強会の表示設計

勉強会の見た目を変更するときに維持する仕様。本文・ノートは `src/data/rag-seminar.ts`、図は `src/components/SeminarDiagram.astro`、表示値は `src/styles/seminar.css` を編集する。

## 参照元と適用範囲

出典： [デジタル庁デザインシステム](https://design.digital.go.jp/dads/) と [公式Markdown配布版（2026年8月19日版）](https://design.digital.go.jp/dads/dads-markdown-20260819.zip)。2026年9月6日に確認し、RAGガイドが発表用に編集・調整して作成した。

これはウェブ向けの原則をHTMLスライドへ応用した独自の表示設計であり、デジタル庁作成のスライドや公式PowerPointテンプレートではない。官公庁ロゴは使わない。フォームなど発表資料に存在しない部品は導入しない。

| 公式資料 | この資料への反映 |
|---|---|
| [タイポグラフィ](https://design.digital.go.jp/dads/foundations/typography/) | サンセリフ、400/700の太さ、役割ごとのサイズ、本文1.5以上の行高 |
| [余白](https://design.digital.go.jp/dads/foundations/spacing/) | 8pxを基準に16・24・32・64pxでまとまりを表現 |
| [レイアウト](https://design.digital.go.jp/dads/foundations/layout/) | 16:9の共通枠、同じ左端、比較は列、処理は流れとして表現 |
| [カラー](https://design.digital.go.jp/dads/foundations/color/) | 白とニュートラル、強調・操作の青、黄と黒の焦点表示 |
| [テーブル](https://design.digital.go.jp/dads/components/table/) | 列・行の見出し、上寄せ、数値右寄せ、見出し下の明確な境界 |
| [利用上の注意](https://design.digital.go.jp/dads/introduction/notices/) | 勉強会案内と操作方法に出典・編集調整の表示 |

## 投影用の基準

1440×810の論理キャンバスを画面に比例縮小する。表の数値はCSS px相当の設計値で、表示時の固定pxではない。発表者の左側は縮小プレビューで、説明原稿は独立した18px・行高1.7の読書領域に表示する。

| 役割 | 基準サイズ | 太さ | 行高 |
|---|---:|---:|---:|
| 表紙 | 64 | 700 | 1.4 |
| スライド見出し | 45 | 700 | 1.4 |
| リード | 32 | 400 | 1.5 |
| 小見出し | 28 | 700 | 1.5 |
| 本文・結論 | 26 | 400 / 700 | 1.5〜1.6 |
| 比較表・6項目の説明 | 24 | 400 / 700 | 1.5〜1.6 |
| 工程図の説明 | 約21〜24 | 400 / 700 | 1.5 |
| 注記・補助情報 | 16〜18 | 400 | 1.5 |

投影画面の見出しと本文は45:26。小さくして文章を詰めるのではなく、詳細を発表者ノートへ置く。技術図内も同じ文字体系で組み、ラスタ画像内の細字へ依存しない。モバイルは固定縮小せず、本文20pxを中心に一列へ再配置し、表のみ横スクロールする。

## 色と装飾

- 背景 `#ffffff`、本文 `#1a1a1c`、補助文字 `#595959`、強調とリンク `#0017c1`。
- 表見出し等の背景 `#f2f2f2`、境界 `#8b8b8b`。意味のある図形の境界には十分なコントラストを確保する。
- キーボードの焦点は黒と `#ffd43d` の二重表示。
- 見出しごとの飾り線、グラデーション、影、装飾アイコンは加えない。罫線は表・グループ・結論の区切りに使う。
- 色に加えて、順位、見出し、ラベル、破線で意味を伝える。

## 維持する内容と検証

全30枚・27小節・6分類、四工程と二層、配置、全説明原稿、30/40分配分を維持する。5技術図はネイティブのHTML/SVGで編集できる。変更後はビルド・サイト検証に加え、公開画面の全ページの欠落・はみ出しと代表図表・発表者画面を確認する。
