# ハンズオンのAWS構成図

物理構成・論理構成は、添付の `aws-architecture-drawio` スキルに基づくdraw.io図へ統一した。
`ArchitectureOverview.astro` は同じ原本から書き出したSVGを表示する。

- このディレクトリの `.drawio`：編集用のコピー。
- 共通原本、出典、再生成手順、検証記録：[`assets/diagrams/aws`](../../../assets/diagrams/aws/)。
- 配信画像：`../public/images/aws-rag-{physical,logical}-architecture.svg`。
- ダウンロード用原本：`../public/diagrams/`。

構成図を変更したら共通原本から再出力し、編集用コピーと公開画像を同時に更新する。
公開ページの図をクリックすると、SVGを別タブで拡大して読める。
