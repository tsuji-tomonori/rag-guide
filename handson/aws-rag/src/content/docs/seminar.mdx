## スライドを開く

**RAGを「4つの工程」と「2つの層」で理解する**ための、全22枚の発表資料です。
LLMを使ったことがあり、RAGの全体像をつかみたい方向けです。数式やAWSの操作手順は、本文とハンズオンで補えます。

[40分の発表スライドを開く](/rag-guide/slides/rag-intro/?duration=40#intro) · [30分の発表スライドを開く](/rag-guide/slides/rag-intro/?duration=30#intro)

## 勉強会の流れ

| パート | スライド | 話すこと |
|---|---|---|
| RAGの概要 | 1〜3 | 社内の質問を例に、検索して根拠から回答する考え方 |
| 4つの工程・2つの層 | 4〜6 | 処理の目的と実行時点を分け、両者の対応を理解する |
| バッチ層の主要技術 | 7〜9 | 資料の管理、チャンク、メタデータ、埋め込み |
| リアルタイム層の主要技術 | 10〜16 | 質問変換、検索、ハイブリッド、再ランキング、根拠集合、生成 |
| 評価・セキュリティ・運用 | 17〜19 | 失敗の切り分け、閲覧権限、非機能と更新 |
| 高度化・AWS・次の一歩 | 20〜22 | 必要に応じた発展方式、AWSの役割、業務への当てはめ |

1時間枠では、**導入・接続確認10分 → 発表30〜40分 → 質疑・予備10〜20分**を目安に使えます。
30分版・40分版は同じスライドを使います。30分版は要点を中心に、40分版は発表者ノートの補足や問いかけを加えます。
発表者画面に各スライドの持ち時間と累積の目安を表示します。時間は話速に合わせて調整してください。

## 発表者の準備と操作

1. スライドを開き、上部の「発表者画面」を押します。別ウィンドウに説明ノート・補足・次のスライド・出典が表示されます。
2. **画面共有はスライドの投影ウィンドウだけ**を選びます。発表者画面は自分の手元に置きます。
3. 発表者画面で30分／40分を選び、話し始めるときに「タイマー開始」を押します。一時停止・再開・リセットもできます。
4. 左右キー、Space、PageUp／PageDown、または「前へ」「次へ」で送ります。両画面が同期します。
5. 「目次」から任意のスライドへ移動できます。「全画面」で投影し、Escで戻ります。操作一覧は「操作方法」で確認できます。

現在のURLを保存すると、そのスライドから開き直せます。タイマーは投影ウィンドウを再読み込みするとリセットされます。
ポップアップがブロックされた場合は、このサイトで許可してから開き直してください。自動同期や全画面の対応はブラウザによります。

ブラウザの印刷では、全スライドを1枚ずつ印刷できます。発表者ノートと操作ボタンは出力されません。
スマートフォンなど狭い画面では縦に読みやすく並べ替え、前後ボタンで移動できます。JavaScriptが無効なら全スライドを縦に表示します。
