発表者画面に各スライドの持ち時間と累積の目安を表示します。時間は話速に合わせて調整してください。

## 発表者の準備と操作

1. スライドを開き、上部の「発表者画面」を押します。別ウィンドウに説明ノート・補足・次のスライド・出典が表示されます。
2. **画面共有はスライドの投影ウィンドウだけ**を選びます。発表者画面は自分の手元に置きます。
3. 発表者画面で30分／40分を選び、話し始めるときに「タイマー開始」を押します。一時停止・再開・リセットもできます。
4. 左右キー、Space、PageUp／PageDown、または「前へ」「次へ」で送ります。両画面が同期します。
5. 「目次」から任意のスライドへ移動できます。「全画面」で投影し、Escで戻ります。操作一覧は「操作方法」で確認できます。

現在のURLを保存すると、そのスライドから開き直せます。タイマーは投影ウィンドウを再読み込みするとリセットされます。
ポップアップがブロックされた場合は、このサイトで許可してから開き直してください。自動同期や全画面の対応はブラウザによります。

ブラウザの印刷では、全スライドを1枚ずつ印刷できます。発表者ノートと操作ボタンは出力されません。
スマートフォンなど狭い画面では縦に読みやすく並べ替え、前後ボタンで移動できます。JavaScriptが無効なら全スライドを縦に表示します。
