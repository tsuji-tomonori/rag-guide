## 完成する構成

分離型：`S3 data source → Amazon Bedrock Knowledge Bases → S3 Vectors → Retrieve → Converse`

一体型：`S3 data source → Amazon Bedrock Knowledge Bases → S3 Vectors → RetrieveAndGenerate → 回答・citation`

基準構成は密ベクトルによるsemantic searchです。7・8では検索結果を見ずに生成へ進まず、まず`Retrieve`で「適切な根拠が返っているか」を確認します。9では同じKnowledge Baseに対して、検索と回答生成を一撃で試します。

## 所要時間と費用

- 所要時間の目安：45〜75分
- 対象リージョン：アジアパシフィック（東京）`ap-northeast-1`
- 1人1回の概算：**約0.005 USD**（基準ケース、税・為替・割引・再実行を除く）
- 主な費用：embedding、S3 Vectorsの保存・API、Knowledge Basesの取り込み、生成モデルの入出力token
- [費用の前提と詳細を見る →](/rag-guide/cost/)
- ハンズオン終了後は必ずCleanupまで実行してください。
