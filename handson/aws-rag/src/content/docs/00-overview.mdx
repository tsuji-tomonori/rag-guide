## ゴール

このハンズオンでは、AWS公式の日本語版RAGガイダンスPDFをAWS CLIから`curl`で取得し、Knowledge Basesでchunk化・embeddingしてS3 Vectorsへ登録します。7・8では`Retrieve`で候補を取得し、呼び出し元でEvidence Setを整えてから`Converse`へ渡します。9では同じKnowledge Baseに対して`RetrieveAndGenerate`を1回呼び出し、検索から回答生成までを一撃で試します。

<Aside type="note" title="採用PDFのRAG 4ステップとの対応">
  採用したAWS PDFは、RAGを「1. 文書を埋め込みとして取り込む」「2. 人が自然言語でクエリする」「3. リトリーバーが類似度検索で関連データを取得する」「4. クエリとコンテキストをLLMへ渡して回答を生成する」の4ステップで説明しています。このハンズオンでは、1をKnowledge Basesの同期、3を`Retrieve`、4を`Converse`として観察します。`RetrieveAndGenerate`は、3と4を一つのAPIで実行する場合の比較対象です。
</Aside>

<Aside type="note" title="この構成で学べる境界">
  Knowledge Basesは取り込みと検索を担当します。7・8では生成をConverseへ分離し、検索結果の`text`、`score`、`source URI`を先に観察できます。9では標準の`RetrieveAndGenerate`を使い、検索と回答生成を一つのAPI呼び出しで確認します。
</Aside>

<Aside type="note" title="1人1回の費用目安">
  基準ケース（PDF 1回取り込み、Retrieve 1回、RetrieveAndGenerate 1回、Converse 2回、同日中にCleanup）では、東京リージョンの公式Price Listに基づき、合計は約`0.005 USD`（税・為替・割引・再実行を除く）です。内訳と計算式は[ハンズオン費用（1人1回）](/rag-guide/cost/)を参照してください。
</Aside>

## 進め方

<Steps>

1. **準備**：AWS CLIの認証、リージョン、CLI機能、モデルを検証します。
2. **バッチ**：文書、vector store、IAM role、Knowledge Base、data sourceを作成して同期します。
3. **リアルタイム**：`Retrieve`で検索結果を確認し、取得した根拠だけを`Converse`へ渡します。さらに`RetrieveAndGenerate`で一体型の実行も試します。
4. **後片付け**：作成したリソースを依存順に削除し、残存がないことを確認します。

</Steps>

## 必要な権限

実習者のIAM principalには、少なくとも次の操作を許可する必要があります。組織のSCP、permissions boundary、session policyで拒否されている場合は、管理者へハンズオン用sandbox accountまたはroleを依頼してください。

| 対象 | 主な権限 |
|---|---|
| STS | `sts:GetCallerIdentity` |
| S3 | bucketとobjectの作成・取得・削除 |
| S3 Vectors | vector bucket、policy、indexの作成・参照・削除 |
| Bedrock | model一覧・呼び出し、Knowledge Base・data source・ingestionの管理、`Retrieve`、`RetrieveAndGenerate` |
| IAM | roleとinline policyの作成・参照・削除、`iam:PassRole` |

<Aside type="caution" title="本番アカウントでは実施しないでください">
  ハンズオンは検証用アカウントで実施してください。作成するKnowledge Base用roleは対象S3 bucket、embedding model、vector indexだけへ権限を限定しますが、実習者自身にはリソース作成権限が必要です。
</Aside>
