<Aside type="danger" title="値を確認してから削除してください">
  このページのコマンドは、このハンズオンで作成したAWSリソースを削除します。`RAG_RUN_ID`と各resource名が現在のrunの値であることを必ず確認してください。別の名前へ置き換えないでください。
</Aside>

<CloudShellStep number="10.1" title="削除対象を固定する">

<Command>

```bash
printf '%-22s %s\n' \
  "run ID" "$RAG_RUN_ID" \
  "knowledge base" "$RAG_KB_ID" \
  "data source" "$RAG_DS_ID" \
  "source bucket" "$RAG_SOURCE_BUCKET" \
  "vector bucket" "$RAG_VECTOR_BUCKET" \
  "vector index" "$RAG_INDEX_NAME" \
  "IAM role" "$RAG_ROLE_NAME"

test -n "$RAG_RUN_ID"
test "${#RAG_KB_ID}" -eq 10
test "${#RAG_DS_ID}" -eq 10
[[ "$RAG_SOURCE_BUCKET" == *"$RAG_ACCOUNT_ID"*"$RAG_RUN_ID" ]]
[[ "$RAG_VECTOR_BUCKET" == *"$RAG_ACCOUNT_ID"*"$RAG_RUN_ID" ]]
[[ "$RAG_ROLE_NAME" == *"$RAG_RUN_ID" ]]
```

</Command>

<ExpectedResult>

すべての名前がこのrun IDを含み、検証コマンドがエラーなく終了します。一つでも失敗した場合は削除を止め、[変数の復元](/rag-guide/troubleshooting/#cloudshellを再起動して変数が消えた)を行います。

</ExpectedResult>

</CloudShellStep>

<CloudShellStep number="10.2" title="data sourceとKnowledge Baseを削除する">

data deletion policyを`DELETE`にしているため、data source削除時に取り込んだvectorの削除も要求されます。service roleはこの処理が終わるまで残します。

<Command>

```bash
aws bedrock-agent delete-data-source \
  --knowledge-base-id "$RAG_KB_ID" \
  --data-source-id "$RAG_DS_ID"

for attempt in {1..30}; do
  if ! aws bedrock-agent get-data-source \
    --knowledge-base-id "$RAG_KB_ID" \
    --data-source-id "$RAG_DS_ID" >/dev/null 2>&1; then
    printf 'data source deleted\n'
    break
  fi
  printf '[%02d/30] waiting for data source deletion\n' "$attempt"
  sleep 10
done

if aws bedrock-agent get-data-source \
  --knowledge-base-id "$RAG_KB_ID" \
  --data-source-id "$RAG_DS_ID" >/dev/null 2>&1; then
  printf 'data source still exists\n' >&2
  exit 1
fi

aws bedrock-agent delete-knowledge-base --knowledge-base-id "$RAG_KB_ID"

for attempt in {1..30}; do
  if ! aws bedrock-agent get-knowledge-base \
    --knowledge-base-id "$RAG_KB_ID" >/dev/null 2>&1; then
    printf 'knowledge base deleted\n'
    break
  fi
  printf '[%02d/30] waiting for knowledge base deletion\n' "$attempt"
  sleep 10
done

if aws bedrock-agent get-knowledge-base \
  --knowledge-base-id "$RAG_KB_ID" >/dev/null 2>&1; then
  printf 'knowledge base still exists\n' >&2
  exit 1
fi
```

</Command>

<ExpectedResult>

`data source deleted`と`knowledge base deleted`が表示され、両方のget APIがNot Foundになります。

</ExpectedResult>

</CloudShellStep>

<CloudShellStep number="10.3" title="S3 Vectorsを削除する">

<Command>

```bash
aws s3vectors delete-vector-bucket-policy \
  --vector-bucket-name "$RAG_VECTOR_BUCKET"

aws s3vectors delete-index --index-arn "$RAG_INDEX_ARN"

for attempt in {1..20}; do
  if ! aws s3vectors get-index --index-arn "$RAG_INDEX_ARN" >/dev/null 2>&1; then
    printf 'vector index deleted\n'
    break
  fi
  printf '[%02d/20] waiting for vector index deletion\n' "$attempt"
  sleep 5
done

if aws s3vectors get-index --index-arn "$RAG_INDEX_ARN" >/dev/null 2>&1; then
  printf 'vector index still exists\n' >&2
  exit 1
fi

aws s3vectors delete-vector-bucket \
  --vector-bucket-name "$RAG_VECTOR_BUCKET"

if aws s3vectors get-vector-bucket \
  --vector-bucket-name "$RAG_VECTOR_BUCKET" >/dev/null 2>&1; then
  printf 'vector bucket still exists\n' >&2
  exit 1
fi
```

</Command>

<ExpectedResult>

vector indexが削除された後、vector bucketもNot Foundになります。

</ExpectedResult>

</CloudShellStep>

<CloudShellStep number="10.4" title="S3とIAM roleを削除する">

<Command>

```bash
aws s3 rm "s3://$RAG_SOURCE_BUCKET" --recursive
aws s3api delete-bucket --bucket "$RAG_SOURCE_BUCKET"

aws iam delete-role-policy \
  --role-name "$RAG_ROLE_NAME" \
  --policy-name "$RAG_POLICY_NAME"
aws iam delete-role --role-name "$RAG_ROLE_NAME"
```

</Command>

<Command title="最終確認">

```bash
RAG_CLEANUP_FAILURES=0

aws s3api head-bucket --bucket "$RAG_SOURCE_BUCKET" >/dev/null 2>&1 && {
  printf 'ERROR: source bucket remains\n' >&2
  RAG_CLEANUP_FAILURES=$((RAG_CLEANUP_FAILURES + 1))
}

aws s3vectors get-vector-bucket --vector-bucket-name "$RAG_VECTOR_BUCKET" >/dev/null 2>&1 && {
  printf 'ERROR: vector bucket remains\n' >&2
  RAG_CLEANUP_FAILURES=$((RAG_CLEANUP_FAILURES + 1))
}

aws iam get-role --role-name "$RAG_ROLE_NAME" >/dev/null 2>&1 && {
  printf 'ERROR: IAM role remains\n' >&2
  RAG_CLEANUP_FAILURES=$((RAG_CLEANUP_FAILURES + 1))
}

test "$RAG_CLEANUP_FAILURES" -eq 0
printf 'cleanup verification: PASS\n'
```

</Command>

<ExpectedResult>

`cleanup verification: PASS`と表示されます。Knowledge Base、data source、vector index、vector bucket、source bucket、IAM roleの残存がありません。

</ExpectedResult>

</CloudShellStep>

<Checkpoint title="ハンズオン完了">

- data sourceとKnowledge BaseがNot Foundである
- vector indexとvector bucketがNot Foundである
- source S3 bucketが存在しない
- Knowledge Base用IAM roleが存在しない
- `cleanup verification: PASS`を確認した

</Checkpoint>

これでハンズオンは完了です。お疲れさまでした。
