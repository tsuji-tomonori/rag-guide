S3 Vectorsにvector bucketとindexを作成します。indexの`dimension`、`distanceMetric`、non-filterable metadata keyは後から変更できないため、Knowledge Baseと接続する前にread-backします。

<CloudShellStep number="3.1" title="ベクトルバケットを作成する">

<Command phase="execute" title="ベクトルバケットを作成">

```bash
aws s3vectors create-vector-bucket \
  --vector-bucket-name "$RAG_VECTOR_BUCKET" \
  --region "$AWS_REGION"
```

</Command>

<Command phase="verify" title="ベクトルバケットを検証する" final>

```bash
aws s3vectors get-vector-bucket \
  --vector-bucket-name "$RAG_VECTOR_BUCKET" \
  --region "$AWS_REGION" \
  --query 'vectorBucket.{name:vectorBucketName,arn:vectorBucketArn,encryption:encryptionConfiguration.sseType}' \
  --output table

export RAG_VECTOR_BUCKET_ARN="$(aws s3vectors get-vector-bucket \
  --vector-bucket-name "$RAG_VECTOR_BUCKET" \
  --region "$AWS_REGION" \
  --query 'vectorBucket.vectorBucketArn' \
  --output text)"
test "$RAG_VECTOR_BUCKET_ARN" != "None"
declare -p RAG_VECTOR_BUCKET_ARN >> "$RAG_STATE_FILE"

printf '[CHECK] vector bucket creation: COMPLETE (%s)\n' "$RAG_VECTOR_BUCKET"
printf '[CHECK] vector bucket ARN saved: %s\n' "$RAG_VECTOR_BUCKET_ARN"
```

</Command>

<ExpectedResult id="s3-1-vector-bucket" verification="ベクトルバケットを検証する">

vector bucket名とARNが表示されます。暗号化を明示しない場合も、S3管理キーによるSSE-S3が既定で適用されます。

```text
| name       | rag-handson-vectors-123456789012-0816071530-a41f92 |
| arn        | arn:aws:s3vectors:ap-northeast-1:123456789012:bucket/... |
| encryption | AES256                                           |
[CHECK] vector bucket creation: COMPLETE (rag-handson-vectors-123456789012-0816071530-a41f92)
[CHECK] vector bucket ARN saved: arn:aws:s3vectors:...
```

- `[CHECK] vector bucket creation: COMPLETE`が表示される
- vector bucket名とARNが表示される
- `RAG_VECTOR_BUCKET_ARN`がstate fileへ保存される
- 暗号化欄が表示される

</ExpectedResult>

</CloudShellStep>

<CloudShellStep number="3.2" title="1024次元のベクトルインデックスを作成する">

Titan Text Embeddings V2の1024次元float vectorへ合わせます。Knowledge Basesがchunk本文と内部metadataを保存できるよう、AWS公式手順で指定される2つのkeyをnon-filterableにします。

<Command phase="execute" title="1024次元のベクトルインデックスを作成">

```bash
aws s3vectors create-index \
  --vector-bucket-name "$RAG_VECTOR_BUCKET" \
  --index-name "$RAG_INDEX_NAME" \
  --data-type float32 \
  --dimension 1024 \
  --distance-metric cosine \
  --metadata-configuration \
    '{"nonFilterableMetadataKeys":["AMAZON_BEDROCK_TEXT","AMAZON_BEDROCK_METADATA"]}' \
  --region "$AWS_REGION"
```

</Command>

<Command phase="verify" title="インデックス設定を読み戻して検証する" final>

```bash
aws s3vectors get-index \
  --vector-bucket-name "$RAG_VECTOR_BUCKET" \
  --index-name "$RAG_INDEX_NAME" \
  --region "$AWS_REGION" \
  --query 'index.{name:indexName,dataType:dataType,dimension:dimension,distance:distanceMetric,metadata:metadataConfiguration.nonFilterableMetadataKeys,arn:indexArn}' \
  --output table

export RAG_INDEX_ARN="$(aws s3vectors get-index \
  --vector-bucket-name "$RAG_VECTOR_BUCKET" \
  --index-name "$RAG_INDEX_NAME" \
  --region "$AWS_REGION" \
  --query 'index.indexArn' \
  --output text)"

test "$(aws s3vectors get-index --index-arn "$RAG_INDEX_ARN" --region "$AWS_REGION" --query 'index.dimension' --output text)" = "1024"
test "$(aws s3vectors get-index --index-arn "$RAG_INDEX_ARN" --region "$AWS_REGION" --query 'index.distanceMetric' --output text)" = "cosine"
declare -p RAG_INDEX_ARN >> "$RAG_STATE_FILE"

printf '[CHECK] vector index creation: COMPLETE (%s)\n' "$RAG_INDEX_NAME"
printf '[CHECK] index data type: float32\n'
printf '[CHECK] index dimension: 1024\n'
printf '[CHECK] index distance metric: cosine\n'
printf '[CHECK] index ARN saved: %s\n' "$RAG_INDEX_ARN"
printf 'vector index verification: PASS\n'
```

</Command>

<ExpectedResult id="s3-2-vector-index" verification="インデックス設定を読み戻して検証する">

`float32`、`1024`、`cosine`、2つの`AMAZON_BEDROCK_*` keyとindex ARNが表示され、`test`がエラーなく終了します。取得したARNはstate fileへ追記されるため、CloudShellを開き直しても復元できます。

```text
| name      | rag-titan-v2-1024 |
| dataType  | float32           |
| dimension | 1024              |
| distance  | cosine            |
| metadata  | AMAZON_BEDROCK_TEXT, AMAZON_BEDROCK_METADATA |
[CHECK] vector index creation: COMPLETE (rag-titan-v2-1024)
[CHECK] index data type: float32
[CHECK] index dimension: 1024
[CHECK] index distance metric: cosine
[CHECK] index ARN saved: arn:aws:s3vectors:...
vector index verification: PASS
```

- `[CHECK] vector index creation: COMPLETE`が表示される
- `float32 / 1024 / cosine`が一致する
- non-filterable metadata keyが2つ表示される
- `RAG_INDEX_ARN`がstate fileへ保存される

</ExpectedResult>

<Aside type="caution" title="S3 VectorsはHYBRID検索ではありません">
  このハンズオンのstoreはdense vectorによるSEMANTIC検索です。AWS PDFでいうリトリーバーの候補取得を意味検索で観察する構成であり、score自体を回答の正しさとは判定しません。BM25などの語彙一致が必要な場合は、OpenSearch Serverless等の対応storeへ変更するか、別retrieverの結果をRRFやrerankerで統合します。
</Aside>

</CloudShellStep>

<Checkpoint>

- vector bucket ARNを`RAG_VECTOR_BUCKET_ARN`へ保存した
- index ARNを`RAG_INDEX_ARN`へ保存した
- 両ARNをstate fileへ永続化した
- indexは`float32 / 1024 / cosine`である
- non-filterable keyはAWS指定の2 keyである

</Checkpoint>
