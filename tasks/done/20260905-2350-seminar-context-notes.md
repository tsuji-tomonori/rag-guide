## 検証計画・PR観点・リスク

### 原稿拡充に伴う操作の確認

事実: `go()` は投影領域のスクロールだけを戻し、発表者欄のスクロールを更新していない。長い原稿の後に次の原稿の冒頭を見失う可能性がある。原因は描画済みページの変化と発表者欄のスクロールを結び付けていないこと。対策はページ変更時だけ発表者欄を先頭へ戻し、同じページの同期・時間変更では読んでいる位置を維持する。DOMで再現し、回帰検証する。実ブラウザでも確認する。

`npm run build`、`npm run test:site`、`git diff --check`。図と原稿の意味を目視確認する。位置効果を普遍的な規則としない。追加原稿の実際の発話時間はリハーサルで調整が必要。公開はこの会話の既存のマージ・公開指示に基づく。
